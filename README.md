Q-Route – Intelligent Vehicle Routing System

 Project Overview

Q-Route is a vehicle routing project designed to organize and manage routing information efficiently. The project provides a foundation for exploring route planning and vehicle management through a web-based application.

 Objectives

- Organize vehicle routing information.
- Improve route planning and management.
- Provide a user-friendly interface.
- Explore efficient transportation and routing solutions.

 Technology Stack

- Frontend: HTML, CSS, TypeScript
- Build Tool: Vite
- Package Management: Bun

📂 Project Structure

- "public/" – Public assets and static resources.
- "src/" – Application source code.
- "index.html" – Main HTML entry point.
- "package.json" – Project dependencies and scripts.
- "vite.config.ts" – Vite configuration.
- "tsconfig.json" – TypeScript configuration.

🚀 Getting Started

Prerequisites

- Node.js
- Bun (if using the Bun lockfile)

Installation

1. Clone the repository:
   
   git clone https://github.com/AllamArya/Q-Route.git

2. Navigate to the project directory:
   
   cd Q-Route

3. Install dependencies using Bun:
   
   bun install

4. Start the development server:
   
   bun run dev
